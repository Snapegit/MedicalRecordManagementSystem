
## 🌟 项目简介

这是一个基于 **Java + SpringBoot + Vue + MySQL** 构建的完整病历管理系统，功能持续优化中...

### 🧩 功能模块一览

- 用户登录 / 注册  
- 患者管理  
- 医生管理 / 坐诊医生管理  
- 科室管理  
- 预约挂号管理  
- 挂号取消管理  
- 电子病历管理  
- 处方记录管理  
- 取药记录管理  
- 药品信息管理 / 药品类型管理  
- 床位信息管理  
- 住院记录管理  
- 通知公告管理  
- 收藏与评论  
- 其它...

## ⚙️ 运行环境与工具要求

为了确保项目顺利运行，请确认您的开发环境满足以下条件：

### ✅ 推荐配置
- **Java**: JDK 1.8  
- **MySQL**: 8.0.41  
- **Node.js**: 16.20.2  

⚠️ *温馨提示：版本不一致可能导致依赖冲突或启动失败。*

### 🛠️ 开发工具推荐
- **后端开发**: IntelliJ IDEA 2022+  
- **前端开发**: VS Code  
- **数据库管理**: Navicat / DBeaver / MySQL Workbench  ...
